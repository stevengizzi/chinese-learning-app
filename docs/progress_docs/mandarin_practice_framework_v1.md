4 modes of comprehension:
1. Listening (receiving sound)
2. Speaking (producing sound)
3. Reading (receiving visual)
4. Writing (producing visual)

3 types of testable data:
1. Audio samples
2. Characters
3. Pinyin

Intersections of testable data and comprehension modes:
1. Audio
    1. Recognition (listening)
    2. Reproduction (speaking)
2. Characters
    1. Recognition (pictogram reading)
    2. Reproduction (pictogram writing)
3. Pinyin
    1. Recognition (phonetic reading)
    2. Reproduction (phonetic writing)

Verification tests:
1. Listen to audio sample -> record speech
2. Listen to audio sample -> identify the characters (from multiple choice)
3. Listen to audio sample -> write the characters
4. Listen to audio sample -> identify the pinyin (from multiple choice)
5. Listen to audio sample -> write the pinyin
6. Read characters -> identify audio (listening multiple choice)
7. Read characters -> record speech
8. Read characters -> write the characters
9. Read characters -> identify the pinyin (from multiple choice)
10. Read characters -> write the pinyin
11. Read pinyin -> identify audio (listening multiple choice)
12. Read pinyin -> record speech
13. Read pinyin -> identify the characters (from multiple choice)
14. Read pinyin -> write the characters
15. Read pinyin -> write the pinyin

Conversational tests:
1. Listen to speech -> respond with speech
2. Listen to speech -> respond with characters
3. Listen to speech -> respond with pinyin
4. Read characters -> respond with speech
5. Read characters -> respond with characters
6. Read characters -> respond with pinyin
7. Read pinyin -> respond with speech
8. Read pinyin -> respond with characters
9. Read pinyin -> respond with pinyin
