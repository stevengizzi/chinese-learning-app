# Mandarin Chinese Practice Framework

This document outlines the **full possibility space** of skills involved in learning and practicing Mandarin Chinese. It is intentionally descriptive rather than prescriptive: it enumerates *what can be trained and tested*, without recommending routines, priorities, or schedules.

The framework is designed to:
- Make implicit language-learning skills explicit
- Separate recognition from production
- Account for Mandarin-specific features (tones, characters, IME typing)
- Scale from isolated units to real conversation

---

## 1. Core Communication Modalities

Mandarin competence can be decomposed along two orthogonal axes:

### 1.1 Channel
1. **Audio** (sound)
2. **Visual** (text)

### 1.2 Direction
1. **Receptive** (input)
2. **Productive** (output)

This yields four fundamental modalities:

1. **Listening** – receiving spoken language
2. **Speaking** – producing spoken language
3. **Reading** – receiving written language
4. **Writing** – producing written language

---

## 2. Representational Data Types

Mandarin uses multiple, partially independent representations of language. Each can be tested and trained separately.

### 2.1 Audio
- Continuous speech sounds
- Includes phonemes, tones, rhythm, and prosody

### 2.2 Characters (Hanzi)
- Logographic / morpho-semantic units
- Often phonetic–semantic compounds
- Not purely pictographic

### 2.3 Pinyin
- Romanized phonetic transcription
- Encodes initials, finals, and tones
- Acts as an explicit phonological bridge

---

## 3. Recognition vs. Reproduction

For every modality and data type, there is a fundamental distinction between:

- **Recognition**: identifying or understanding a form when presented
- **Reproduction**: producing the correct form from memory or intent

This distinction applies independently across audio, characters, and pinyin.

---

## 4. Base Skill Matrix: Data Type × Capability

### 4.1 Audio
1. **Audio Recognition**
   - Hearing speech and identifying words, tones, or meaning
2. **Audio Reproduction**
   - Producing spoken Mandarin with correct sounds and tones

### 4.2 Characters
1. **Character Recognition**
   - Visually identifying characters and accessing meaning and/or pronunciation
2. **Character Reproduction**
   - Producing characters correctly

### 4.3 Pinyin
1. **Pinyin Recognition**
   - Reading pinyin and accessing intended sounds/tones
2. **Pinyin Reproduction**
   - Writing pinyin accurately from sound or meaning

---

## 5. Character Production Subtypes

Character reproduction is not a single skill. It can be decomposed into distinct production mechanisms:

1. **Handwriting (Motor Production)**
   - Recalling stroke order and form
   - Engages motor and spatial memory

2. **Typing via Pinyin IME (Lexical Selection)**
   - Converting phonology into characters
   - Requires correct sound + tone category
   - Reinforces audio–character mapping without motor memory

3. **Selection / Recognition-Based Entry**
   - Choosing characters from candidate lists or menus
   - Lower production burden, higher recognition reliance

---

## 6. Verification Test Space (Single-Item, Non-Interactive)

These tests verify correctness without requiring real-time interaction.

### 6.1 Audio as Input
1. Listen → reproduce speech
2. Listen → identify characters (recognition)
3. Listen → write characters (handwriting or typing)
4. Listen → identify pinyin
5. Listen → write pinyin

### 6.2 Characters as Input
6. Read characters → identify audio
7. Read characters → reproduce speech
8. Read characters → write characters
9. Read characters → identify pinyin
10. Read characters → write pinyin

### 6.3 Pinyin as Input
11. Read pinyin → identify audio
12. Read pinyin → reproduce speech
13. Read pinyin → identify characters
14. Read pinyin → write characters
15. Read pinyin → write pinyin

---

## 7. Conversational / Interactive Test Space

These tests require active response and simulate communicative use.

### 7.1 Audio Input
1. Listen → respond with speech
2. Listen → respond with characters
3. Listen → respond with pinyin

### 7.2 Character Input
4. Read characters → respond with speech
5. Read characters → respond with characters
6. Read characters → respond with pinyin

### 7.3 Pinyin Input
7. Read pinyin → respond with speech
8. Read pinyin → respond with characters
9. Read pinyin → respond with pinyin

---

## 8. Tone as a First-Class Dimension

Tones are categorical features of Mandarin that cut across all audio-related skills.

### 8.1 Tone Perception
- Distinguishing tone categories in listening
- Including minimal pairs and tone sandhi contexts

### 8.2 Tone Production
- Producing stable, intelligible tones in speech
- Maintaining tone under speed and sentence context

### 8.3 Tone–Lexeme Binding
- Correctly associating tones with specific words
- Preventing tone drift or substitution

---

## 9. Temporal Dimension: Speed and Latency

Accuracy alone is insufficient for communicative competence.

### 9.1 Recognition Latency
- Time required to understand audio or text

### 9.2 Production Latency
- Time required to retrieve and produce words or structures

Latency is a critical differentiator between passive knowledge and usable fluency.

---

## 10. Unit Size and Linguistic Scope

All previously described skills apply at multiple linguistic levels:

1. **Syllable / Sound**
2. **Word / Lexeme**
3. **Phrase / Chunk**
4. **Sentence**
5. **Multi-turn Discourse**

As unit size increases, additional constraints emerge (grammar, pragmatics, discourse coherence).

---

## 11. Grammatical and Pragmatic Binding

Beyond individual forms, Mandarin competence includes:

- Word order and topic–comment structure
- Aspect particles (了, 过, 着)
- Classifiers and measure words
- Contextual appropriateness and register

These operate across modalities but become visible primarily at phrase and sentence levels.

---

## 12. Summary

This framework defines a **complete space of Mandarin learning capabilities**, spanning:
- Modalities (listening, speaking, reading, writing)
- Representations (audio, characters, pinyin)
- Capabilities (recognition, reproduction)
- Production mechanisms (speech, handwriting, typing)
- Linguistic scale (sounds → discourse)
- Performance dimensions (accuracy, tone, speed)

It intentionally makes no claims about priority or efficiency. Those emerge only when this space is constrained by learner goals, time, and context.
